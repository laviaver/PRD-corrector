# PRD Best Practices (local reference – update monthly)

Compare the PRD against these criteria:

## Document structure
- Executive summary or problem statement present
- Goals and objectives specified
- Success metrics or KPIs defined
- User stories or requirements listed
- Technical requirements section
- Timeline or milestones
- Risks and mitigation
- Open questions or assumptions

## Quality
- Requirements specific and measurable
- Acceptance criteria for user stories
- Clear, unambiguous language
- No vague technical detail
